주요 기능

생산성 앱의 본질에만 집중했어요. 빠르게 입력하고, 자동으로 정리되고, 어디서든 동기화되는 것.

🤖

AI 자연어 입력

"내일 오전 10시 팀 미팅" → Gemini 2.5 Flash가 날짜·태그·우선순위를 자동 추출합니다.

📅

Google 캘린더 연동

BrioDo 전용 캘린더로 양방향 동기화. 추가·수정·완료가 즉시 반영됩니다.

🎤

음성 인식 입력

말하는 대로 할 일이 만들어집니다. Android 네이티브 STT로 빠르게 기록.

🌐

오프라인 우선

인터넷이 없어도 완벽하게 동작. 온라인 복귀 시 클라우드에 자동 머지됩니다.

🏆

38개 업적 시스템

할 일을 완료할수록 업적 해금. 연속 달성일 · 완료율을 게이미피케이션으로 추적.

🔔

알림 / 반복

정각·10분 전·1시간 전 알림. 매일·매주·매월 반복 일정 지원.

🏠

홈 위젯 + 상태바

홈 화면 위젯과 상태바 상주 알림으로 오늘 할 일을 한눈에.

📊

컬렉션 & 통계

주간·월간·연간 완료율, 연속 달성일, 태그별 집계까지.

🎨

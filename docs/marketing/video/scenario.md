# 30초 데모 영상 시나리오

**관련 이슈**: [#256](https://github.com/jeiel85/BrioDo/issues/256)
**총 길이**: 30초
**디바이스**: Galaxy S24 (1080×1920 portrait, 60fps)
**목적**: Play Store 헤더 + 유튜브 비공개 백업(인플루언서 시드용)

## 컷리스트

| 시간 | 씬 | 설명 | 자막 (한/영) |
|------|----|------|------------|
| 0~3s | 잠금화면 노출 | S24 잠금화면, BrioDo 위젯에 오늘 할 일 3개 보임 | "잠금 해제 없이" / "Without unlocking" |
| 3~6s | 위젯 인터랙션 | 위젯 내 "+ 추가" 버튼 탭 → 인라인 입력창 등장 → "내일 회의" 입력 → 체크 | "잠금화면에서 바로" / "Right on the lock screen" |
| 6~10s | 잠금 해제 + 메인 진입 | 자연스러운 잠금 해제 → BrioDo 메인 화면 (오늘 할 일 list) | (자막 없음) |
| 10~17s | AI 자연어 입력 | 스마트 입력 모달 오픈 → "내일 오후 3시 팀 회의 #업무" 입력 → AI 분석 표시 → 결과 카드 | "AI가 알아서" / "AI does the rest" |
| 17~22s | 캘린더 동기화 | 결과 todo 카드 → Google 캘린더 앱으로 전환 → 같은 일정 등장 | "Google 캘린더 자동 동기화" / "Auto-synced to Google Calendar" |
| 22~26s | 음성 입력 | BrioDo 다시 진입 → 음성 입력 버튼 → 한국어 음성 → 텍스트 변환 + 파싱 | "음성으로도" / "Voice input too" |
| 26~30s | 로고 + 태그라인 | BrioDo 로고 + 1줄 가치 제안 + Play Store 마크 | "Do it with brio. ⚡" |

## 음악 / SFX

- BGM: 저작권-free, 80~100 BPM, 가벼운 일렉트로닉 또는 미니멀 피아노
  - 후보: YouTube Audio Library / Pixabay / Mixkit
- SFX:
  - 위젯 탭: 짧은 click
  - AI 분석 완료: 부드러운 chime
  - 캘린더 등장: subtle ping

# 오해/사용법 안내 응답 템플릿

## 사용 시점
- 사용자가 기능을 잘못 이해했거나 사용 방법을 찾지 못해 부정적 평가를 남긴 경우
- 별점 1~3점

## 한국어

```
[사용자명]님, BrioDo 개발자 박용은입니다.

[사용자가 표현한 불편함]에 대해 답변드립니다. 사실 [정확한 사용법 안내]을(를) 통해 [원하는 결과]가 가능합니다.
- 메뉴 위치: [구체적 경로]
- 단축 동작: [있다면 명시]

설명이 충분하지 않아 헷갈리셨다면 제 잘못입니다. 다음 업데이트에서 [개선 약속 — UI 명확화 / 온보딩 추가 등]을 반영하겠습니다.

도움이 되셨다면 별점 재평가도 고려해 주시면 큰 힘이 됩니다. 감사합니다.
```

## English

```
Hi [username], this is Yongeun Park, the developer of BrioDo.

About [the issue you raised] — you can actually achieve [the desired outcome] by [the actual way to do it]:
- Menu location: [specific path]
- Shortcut: [if any]

If the path wasn't clear, that's on me. We'll improve this in the next update by [UI clarification / better onboarding / etc.].

If this helps, a rating update would mean a lot. Thank you.
```

## 日本語

```
[ユーザー名]様、BrioDo開発者の朴です。

[ユーザーが指摘した不便さ] について、実は [正しい使い方の案内] により [望む結果] が可能です。
- メニュー位置: [具体的なパス]
- ショートカット: [あれば]

説明が分かりにくかったのは私の責任です。次回アップデートで [UI明確化 / オンボーディング追加など] を反映いたします。

お役に立てましたら、評価の更新もご検討いただければ幸いです。ありがとうございます。
```

## 中文

```
[用户名]您好，我是BrioDo开发者朴。

关于您提到的 [不便之处]，其实通过 [正确的使用方法] 可以实现 [期望的结果]：
- 菜单位置: [具体路径]
- 快捷操作: [如有]

如果路径不够清晰，是我的责任。下次更新中将改进 [UI明确化 / 增加引导等]。

如果这有所帮助，期待您能重新评价。谢谢您。
```

## 작성 체크리스트
- [ ] 사용자 의도를 비판하지 않음
- [ ] 정확한 사용 방법을 구체적 경로로 안내
- [ ] UI/설명 부족을 개발자 책임으로 인정
- [ ] 다음 업데이트에서의 개선 약속
- [ ] 정중한 별점 재평가 요청 (강요 없이)

# 긍정 리뷰 응답 템플릿

## 사용 시점
- 별점 4~5점, 긍정 표현 위주의 리뷰
- 의무는 아니지만, 응답하면 충성 사용자 확보 + 다른 잠재 사용자에게 긍정 신호

## 한국어

```
[사용자명]님, 감사합니다! BrioDo 개발자 박용은입니다.

[칭찬받은 부분]을(를) 마음에 들어 해 주셔서 정말 기뻐요. 솔로 개발자에게 이런 리뷰는 진짜 큰 힘이 됩니다.

다음에는 [곧 출시될 기능 또는 개선 — 1줄]도 준비 중이니 기대해 주세요. 좋은 의견은 언제든 환영합니다.
```

## English

```
Thank you so much, [username]! This is Yongeun Park, the developer.

I'm really glad you enjoy [the feature/aspect they praised]. For a solo developer, reviews like this mean everything.

Coming soon: [one-line preview of an upcoming feature or improvement]. Looking forward to hearing more from you anytime.
```

## 日本語

```
[ユーザー名]様、ありがとうございます！BrioDo開発者の朴です。

[褒められた部分]を気に入っていただけて本当に嬉しいです。個人開発者にとって、このようなレビューは本当に大きな励みになります。

次は [近日リリース予定の機能や改善 — 1行] も準備中ですので、ご期待ください。いつでもご意見をお寄せください。
```

## 中文

```
[用户名]您好，非常感谢！我是BrioDo开发者朴。

很高兴您喜欢 [被赞美的部分]。对独立开发者来说，这样的评价是莫大的鼓励。

接下来 [即将推出的功能或改进 - 一行简介] 也在准备中，敬请期待。欢迎随时分享您的意见。
```

## 작성 체크리스트
- [ ] 진심 어린 감사 (의례적 표현 지양)
- [ ] 사용자가 칭찬한 구체적 부분 reference
- [ ] 솔로/소규모 개발자임을 어필 (공감대 형성)
- [ ] 다음 기능 1줄 미리보기 (재방문 동기)
- [ ] 길게 쓰지 않기 (3~5문장)

# 버그 리포트 응답 템플릿

## 사용 시점
- 사용자가 명확히 동작 오류 / 크래시 / 예상과 다른 동작을 보고한 경우
- 별점 1~3점

## 한국어

```
[사용자명]님, BrioDo 개발자 박용은입니다.

[문제 요약]을(를) 겪으셨다니 정말 죄송합니다. [구체적 원인 또는 재현 조건]을 확인해 보고 다음 업데이트 (v[X.Y], 예상 출시 [날짜])에서 우선 수정하겠습니다.

가능하시면 사용 기기와 OS 버전을 알려주시면 더 빠르게 해결할 수 있습니다.

소중한 피드백 감사합니다.
```

## English

```
Hi [username], this is Yongeun Park, the developer of BrioDo.

I'm truly sorry you encountered [issue]. We're investigating [specific cause/conditions] and will prioritize a fix in our next update (v[X.Y], targeting [date]).

If you could share your device model and OS version, we can resolve this even faster.

Thank you for taking the time to report this.
```

## 日本語

```
[ユーザー名]様、BrioDo開発者の朴です。

[問題]が発生してしまい、誠に申し訳ありません。[具体的な原因/再現条件]を確認し、次のアップデート (v[X.Y]、[日付]リリース予定) で優先的に修正いたします。

ご使用の端末とOSバージョンを教えていただけますと、より早く解決できます。

貴重なフィードバックをありがとうございます。
```

## 中文

```
[用户名]您好，我是BrioDo开发者朴。

让您遇到[问题]，我深表歉意。我们正在调查[具体原因/重现条件]，并将在下一次更新 (v[X.Y]，预计[日期]发布) 中优先修复。

如果方便，请告知您的设备型号和系统版本，这样我们可以更快解决问题。

感谢您宝贵的反馈。
```

## 작성 체크리스트
- [ ] 사용자 닉네임 또는 "고객님" 호칭
- [ ] 구체적 문제 요약 (사용자 표현 반영)
- [ ] 사과 + 책임 인정
- [ ] 수정 시한 (버전 + 예상 날짜)
- [ ] 디바이스/OS 정보 요청 (재현용)
- [ ] 감사 표현 마무리

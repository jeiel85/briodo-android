# 기능 요청 응답 템플릿

## 사용 시점
- 사용자가 특정 기능 추가/개선을 요청한 경우
- 별점 무관 (단, 별점 1~3점에는 더 정중하게)

## 한국어

```
[사용자명]님, 의견 정말 감사합니다. BrioDo 개발자 박용은입니다.

[요청 기능 요약] 의견을 잘 받았습니다. [수용 가능성 — 1가지 선택]
- 곧 반영: "이미 로드맵 [Month X]에 포함되어 있고, v[X.Y]에서 만나보실 수 있습니다."
- 검토 중: "흥미로운 제안이라 우선순위를 검토해 보겠습니다. 결과는 다음 업데이트 노트에 공유하겠습니다."
- 어려운 경우: "BrioDo의 방향(간결함/AI 중심)과는 거리가 있어 당장은 어렵지만, 비슷한 효과를 줄 수 있는 [대안]을 고려해 보겠습니다."

추가 의견은 GitHub 이슈(github.com/jeiel85/BrioDo/issues)에서도 환영합니다.

좋은 하루 보내세요.
```

## English

```
Hi [username], thank you so much for the suggestion. This is Yongeun Park, the developer.

[Brief restate of the requested feature] — got it. [Pick one]
- Coming soon: "This is already on our roadmap for [Month X] and will land in v[X.Y]."
- Under review: "This is an interesting suggestion. We'll review priority and share the outcome in the next update notes."
- Hard to commit: "This is somewhat outside BrioDo's core direction (minimalism + AI), but we'll consider an alternative like [alternative] that could give similar value."

Additional feedback is also welcome on GitHub: github.com/jeiel85/BrioDo/issues

Have a great day.
```

## 日本語

```
[ユーザー名]様、ご意見ありがとうございます。BrioDo開発者の朴です。

[要望機能の要約]について承りました。[1つ選択]
- まもなく対応: 「すでにロードマップ [Month X] に含まれており、v[X.Y]で対応予定です。」
- 検討中: 「面白いご提案です。優先度を検討の上、次回アップデートノートで結果をお知らせします。」
- 対応困難: 「BrioDoの方向性 (シンプル/AI中心) とは少し異なるため当面は難しいですが、[代替案]の検討は可能です。」

追加のご意見は GitHub (github.com/jeiel85/BrioDo/issues) でも歓迎します。

良い一日をお過ごしください。
```

## 中文

```
[用户名]您好，非常感谢您的建议。我是BrioDo开发者朴。

[功能请求摘要] 已收到您的反馈。[选择一项]
- 即将上线: "此功能已在路线图 [Month X] 中，将在 v[X.Y] 版本中推出。"
- 评估中: "这是一个有趣的建议。我们将评估优先级，并在下次更新说明中分享结果。"
- 暂难实现: "这与BrioDo的核心方向 (极简 + AI) 略有差异，目前实现较难。我们可以考虑类似的替代方案 [备选方案]。"

更多建议也欢迎到 GitHub (github.com/jeiel85/BrioDo/issues) 提交。

祝您愉快。
```

## 작성 체크리스트
- [ ] 감사 표현 먼저
- [ ] 요청 내용 재진술 (들었다는 확인)
- [ ] 수용 가능성 명확 표현 (3가지 중 1택)
- [ ] 시한 또는 의사결정 일정 명시
- [ ] 추가 의견 채널 안내
- [ ] 거절 시에도 대안 제시

## 1️⃣ 코드 측면 — 자동화됨

### `npm run release 1.1.12` 실행 시 자동 처리

- ✅ `src/App.jsx` APP_VERSION 1.1.11 → **1.1.12**
- ✅ `android/app/build.gradle` versionName 1.1.11 → **1.1.12**, versionCode 23 → **24**
- ✅ git commit (`bump:` 메시지)
- ✅ git push origin main
- ✅ git tag v1.1.12 + push
- ✅ GitHub Actions가 서명 APK + AAB 빌드 → GitHub Release 자동 생성

### 실행 명령

```bash
npm run release 1.1.12
```

## 2️⃣ Play Console 수동 작업 — 필수

### A. AAB 업로드

1. [GitHub Releases v1.1.12](https://github.com/jeiel85/BrioDo/releases/tag/v1.1.12)에서 **AAB 파일 다운로드** (CI 빌드 완료 후 ~10분)
2. [Play Console](https://play.google.com/console/) → BrioDo → **출시 > 프로덕션 > 새 출시 만들기**
3. **앱 번들 추가** → 다운받은 AAB 업로드

### B. 출시 노트 입력

[`whats-new-v1.1.12.md`](./whats-new-v1.1.12.md)에서 4개 언어 카피 복사:

- [ ] **한국어 (ko-KR)**
- [ ] **English (en-US)**
- [ ] **日本語 (ja-JP)**
- [ ] **中文 (zh-CN)** (또는 zh-TW)

각 언어 탭에서 입력란에 붙여넣기. 4개 모두 입력 안 하면 해당 언어 사용자는 *이전 노트가 그대로 노출*됨.

### C. 🚨 데이터 안전 섹션 갱신 (Analytics 추가 신고)

**이 단계를 빠뜨리면 Play 정책 위반입니다.**

[Play Console] → **앱 콘텐츠 > 데이터 안전성 > 양식 편집**

#### 새로 추가/확인할 항목

| 데이터 유형 | 수집 여부 | 공유 여부 | 목적 | 선택 항목? |
|------------|---------|---------|------|---------|
| **앱 상호작용** (인앱 검색, 다른 사용자 활동) | ✅ 수집 | ❌ 공유 안 함 | 분석, 앱 기능 | 아니요 |
| **앱 정보 및 성능** (충돌 로그, 진단) | ✅ 수집 (이미 있을 수 있음) | ❌ | 분석, 앱 기능 | 아니요 |
| **기기 또는 기타 ID** (광고 ID, Firebase Installation ID) | ✅ 수집 | ❌ | 분석 | 아니요 |

**중요 표기**:
- 데이터는 **전송 중 암호화** ✅
- 사용자가 **데이터 삭제 요청 가능** ✅ (Google 계정 삭제 시 자동)
- **Firebase Analytics** SDK 명시

### D. 개인정보 처리방침 확인

분석/측정 데이터 수집을 명시하는지 확인. 없으면 추가:

> "당사는 서비스 개선을 위해 익명화된 사용 통계(앱 실행 시각, 화면 전환, 기능 사용 빈도 등)를 수집합니다. Firebase Analytics를 통해 처리되며 개인 식별 정보(이름, 이메일, 할 일 내용 등)는 포함되지 않습니다."

문서 위치 확인: [현재 개인정보 처리방침 URL](https://briodo.app/privacy 또는 GitHub Pages — 확인 필요)

## ✅ 최종 체크

출시 진행 직전 다음을 확인:

- [ ] `npm run lint` 통과
- [ ] `npm run build` 통과
- [ ] `npm run test:nlp:dry` 통과
- [ ] (선택) `npm run test:unit` 통과
- [ ] `.env`에 `VITE_FIREBASE_MEASUREMENT_ID` 설정됨 (CI가 빌드 시 주입)
- [ ] GitHub Actions Secrets에 `VITE_FIREBASE_MEASUREMENT_ID` 등록 ← **확인 필요**

> ⚠️ **마지막 항목이 중요**: 로컬 `.env`에만 있고 GitHub Actions Secrets에 없으면 CI 빌드에서 measurementId가 누락되어 *실 사용자 측정이 안 됩니다*. [GitHub repo Settings > Secrets and variables > Actions](https://github.com/jeiel85/BrioDo/settings/secrets/actions)에서 `VITE_FIREBASE_MEASUREMENT_ID` 추가.

CI 워크플로우에서 이 secret을 빌드 환경변수로 주입하는지도 확인 필요. 없으면 ci.yml 수정 필요.

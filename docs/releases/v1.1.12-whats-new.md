## ⚠️ 카피 작성 시 주의

1. **거짓말 X**: "큰 업데이트"라고 안 쓰는 이유 — 실제로 그렇지 않으니까. 별점 1점 사유 1순위가 "변경사항 없는데 업데이트만 시킨다"임.
2. **다음 업데이트 예고**: 다음 버전에서 만날 가시 변화를 명시 → 재방문 동기.
3. **개인정보**: Analytics 도입을 솔직하게 알림. 숨기면 데이터 안전 섹션 위반.
4. **개발자 정체성**: 솔로 개발자 톤으로 마무리 → 친밀감, 별점 +alpha.
5. **이모지**: Play 정책상 과도한 이모지는 노출 페널티. 카피 본문에 1개도 안 넣음.

## 📋 Play Console 업로드 절차

1. **출시 > 프로덕션** 좌측 메뉴
2. **새 출시 만들기** 클릭
3. **앱 번들 추가** → GitHub Release `v1.1.12` 페이지에서 다운받은 **AAB** 업로드 (CI가 자동 빌드)
4. **출시 세부 정보** 섹션 → **출시 노트** 입력란에 위 4개 언어 카피 붙여넣기
   - 언어 탭 전환 후 각각 입력
5. **검토** → **프로덕션으로 출시**
6. Play 심사: 1~3시간 (보통) ~ 48시간 (간헐적)
